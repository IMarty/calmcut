# @calmcut/phobias

Profils de phobies déclaratifs — brique publiée de [CalmCut](https://github.com/IMarty/calmcut), un outil gratuit qui protège
les personnes phobiques pendant qu'elles regardent des films.

```bash
bun add @calmcut/phobias
```
