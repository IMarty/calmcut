# `tools/seed` — jeux de données de développement

**Jalon : M3.** `bun run tools:seed`

Peuple la base D1 locale avec des titres, des segments et des index de synchro **synthétiques**.

Aucun contenu réel : les index sont générés à partir de faux dialogues, pour que le dépôt et les
environnements de dev ne contiennent jamais de donnée dérivée d'une œuvre protégée.
